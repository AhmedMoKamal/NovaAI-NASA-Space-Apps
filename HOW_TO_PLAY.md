# 🎮 How to Play NOVA: Echoes in the Dust

## 1. Download
Go to the **[Releases page](https://github.com/AhmedMoKamal/NovaAI-NASA-Space-Apps/releases/latest)** and download **`NovaAI_Game.zip`** (about 470 MB).

Direct link: https://github.com/AhmedMoKamal/NovaAI-NASA-Space-Apps/releases/latest/download/NovaAI_Game.zip

## 2. Unzip
1. Open your **Downloads** folder.
2. **Right-click** `NovaAI_Game.zip` and choose **Extract All...**
3. Click **Extract**. A folder called **`Windows`** appears.

> Don't play from inside the zip. Always extract it first.

## 3. Play
Open the extracted **`Windows`** folder. There are two ways to start the game:

| File | Graphics | Use it when |
|---|---|---|
| **`NovaAI.exe`** | DirectX 11 | **Start here.** Works on almost every Windows PC. |
| **`Play NOVA (DirectX 12 - optional).bat`** | DirectX 12 | You have a newer graphics card (e.g. NVIDIA RTX / AMD RX) **with up-to-date drivers**. |

Double-click your choice. If the DirectX 12 version closes right after starting, use `NovaAI.exe` instead, or update your graphics driver.

**Windows warning?** If Windows says "Windows protected your PC", click **More info** and then **Run anyway**.
That appears because the game isn't signed by a big publisher.

**First launch:** the game prepares its graphics the first time, so the first minute can be a bit slow. That's normal.

## Controls
| On foot | |
|---|---|
| W A S D | Move |
| Mouse | Look |
| Space | Jump |
| Shift | Sprint |
| Left click | Interact / inspect a glowing part |

| Inspecting a part | |
|---|---|
| Hold left click + drag | Rotate |
| Mouse wheel | Zoom |
| Space | Replay Nova's explanation |
| R | Reset view |
| Backspace or right click | Back to the Moon |

| Flying the spaceship | |
|---|---|
| W A S D | Fly |
| Mouse | Look |
| Space / Ctrl | Rise / descend |
| Shift | Boost |
| X | Brake |
| E | Leave the seat (after landing) |

## Requirements
- Windows 10 or 11 (64-bit)
- A graphics card that supports DirectX 11 (DirectX 12 optional)
- About 1 GB of free disk space
